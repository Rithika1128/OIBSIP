# Wine Quality Analysis & Prediction

## Project Overview

This project was completed as part of the OIBSIP Data Analytics Internship. It involves analyzing a red wine quality dataset using Python, performing data cleaning and exploratory data analysis (EDA), visualizing relationships between wine properties, and building a Linear Regression model to predict wine quality.

## Objective

To explore the factors associated with wine quality and use data-driven techniques to predict quality scores.

## Dataset

* **Dataset:** Red Wine Quality
* **Original records:** 1,599
* **Records after removing duplicates:** 1,359
* **Features:** 11 wine properties
* **Target:** Wine quality score

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Project Workflow

1. Loaded and cleaned the dataset.
2. Explored the data using descriptive statistics.
3. Visualized feature relationships using a correlation heatmap.
4. Separated the features and target variable.
5. Split the data into training and testing sets.
6. Trained a Linear Regression model.
7. Evaluated the model and compared actual vs. predicted quality scores.

## Model Performance

The Linear Regression model achieved the following results:

| Metric                    | Score |
| ------------------------- | ----: |
| Mean Absolute Error (MAE) |  0.50 |
| Mean Squared Error (MSE)  |  0.43 |
| R² Score                  |  0.39 |

The model identified patterns in the data, but its predictions could be improved.

## Conclusion

This project helped me gain practical experience in data preprocessing, exploratory data analysis, data visualization, and basic Machine Learning. It also helped me understand how to train and evaluate a predictive model.
