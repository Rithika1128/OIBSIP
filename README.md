### Task 1 — Retail Sales Exploratory Data Analysis

Analyzed retail sales data to identify trends in revenue, product categories, customer demographics, and geographical regions.

**Key activities:**

* Data cleaning and exploratory data analysis
* Sales and revenue trend analysis
* Product category and customer demographic analysis
* Data visualization and insight generation

[View Task 1 Project](https://github.com/Rithika1128/OIBSIP/tree/main/DataAnalytics-L1-EDARetailSales)

### Task 2 — Airbnb Data Cleaning

Cleaned and prepared Airbnb listing data to improve data quality and consistency.

**Key activities:**

* Handling missing values and duplicate records
* Correcting data types and inconsistent formatting
* Identifying invalid values
* Preparing a cleaned dataset for further analysis

[View Task 2 Project](https://github.com/Rithika1128/OIBSIP/tree/main/DataAnalytics-L1-Task2-Airbnb_Data_Cleaning)

### Task 3 — Google Play Store Analysis

Analyzed Google Play Store applications and user reviews to understand app categories, ratings, installation patterns, pricing, estimated revenue, and customer sentiment.

**Key activities:**

* Data cleaning and preprocessing
* App category distribution and rating analysis
* App size versus installs correlation analysis
* Free versus paid app comparison
* Paid app price distribution and estimated revenue analysis
* Sentiment analysis of user reviews using VADER
* Category-wise sentiment analysis
* Interactive data visualization using Plotly

**Note:** Estimated revenue is a calculated proxy based on listed prices and installation counts, not verified actual earnings.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, VADER Sentiment Analysis, Plotly.

[View Task 3 Project](https://github.com/Rithika1128/OIBSIP/tree/main/DataAnalytics-L2-Google_Play_Store_Analysis)
